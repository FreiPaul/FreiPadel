# Using FreiPadel

## First run

Open the app and register without an invite. The first account becomes the
admin. Every account after that needs an invite.

## Inviting the others

As admin, go to **Invites**, create an invite link and send it. There are three
kinds:

- **one-time**: works for exactly one registration and is then spent
- **group**: stays open and counts how often it was used
- **email**: bound to one address, only that address can redeem it

Every invite belongs to exactly one club, by default the club you are currently
in. An admin can disable an open invite at any time, which stops further
registrations through it.

## Availability

Under **My availability**, pick the weekdays and the time window you can play,
for example weekdays between 19:00 and 21:00.

**Available slots** then shows only the free courts inside that window, grouped
by date. Courts at the same date, time and location are collapsed into one row,
so a club with six identical courts does not fill the page.

## Slot polls

1. On **Available slots**, hit **Start slot poll**, tick the slots worth
   considering and give the poll a name.
2. Everyone sees it under **Active slot polls** and votes yes or no on each
   slot.
3. A slot with four yes votes is a full match and is highlighted.
4. The poll creator closes the poll and picks the slot to play.

Booking the court itself still happens on the provider's own site.

## Clubs

A member can belong to several clubs and switches between them. Availability,
slots, polls and invites always belong to the club that is currently active.
An admin manages a club's locations and its members.

## Notifications

Under **Settings**, each member chooses whether to be notified when a poll is
created and when a slot is booked. Notifications go out by email and Telegram,
depending on what the deployment has configured.
